# 云中书作品廊

设计并开发一个以笔名“云中书”为核心的个人主页网站，风格呈现科技感与未来感。核心功能为一个3D互动展示廊，陈列所有“AI”主题作品，整个页面是一个 3D 画廊空间，用户支持在里面走动（可通过鼠标，键盘，支持视角等）的感觉。具体要求如下：1. 3D展示廊支持鼠标拖拽旋转与缩放，作品以悬浮卡片或3D模型呈现，点击查看详情与创作理念；2. 个人主页包含“关于我”版块（介绍背景与AI探索）及联系方式；3. UI采用深色系背景搭配霓虹光效，契合AI主题，并确保响应式布局兼容移动端。4. 作品数据字段包含名称、简介、跳转链接及可选视频（作品廊展示时支持播放）。5. 作品廊空间添加签名墙留言功能，用户可录入手写签名并输入评论，签名展示于墙上，鼠标悬浮签名时浮现评论信息。
