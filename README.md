# 云中书作品廊

设计并开发一个以笔名“云中书”为核心的个人主页网站，风格呈现简洁清晰的作品展览风格。核心功能为一个3D互动展示廊，陈列所有“AI”主题作品，整个页面是一个 3D 画廊房间空间，用户支持在里面走动（可通过鼠标，键盘，支持视角等）的感觉。具体要求如下：1. 3D展示廊支持鼠标拖拽旋转与缩放，作品以悬浮卡片或3D模型呈现，点击查看详情与创作理念（操作和游戏 CS 或者房屋 VCR 相似）；2. 个人主页包含“关于我”版块（介绍背景与AI探索）及联系方式；3. UI采用简洁白色系背景搭配“云中书”主题，有种云中查看作品书籍展览布局，契合AI主题，并确保响应式布局兼容移动端。4. 作品数据字段包含名称、简介、跳转链接及可选视频（作品廊展示时支持播放）。5. 作品廊单独设计一面墙添加签名墙留言功能，用户可录入手写签名并输入评论，签名展示于墙上，鼠标悬浮签名时浮现评论信息。6. 支持作品的扩展，作品的维护放到一个统一的 JSON 文件中，方便后续扩展。
